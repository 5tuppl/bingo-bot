# 🎲 Бинго-бот для Telegram-чата

Бот воспроизводит механику "чатового бинго": участники отвечают на сообщение
со списком пятью числами (1–99), админ тянет числа, побеждает тот, чьи
5 чисел выпали первыми. Весь интерфейс — на русском.

## Как играть

1. Админ пишет в группе `/бинго` — бот публикует список:
   `🏆 Бинго Список: Открыт ✅ Для записи ответьте на это сообщение 5 числами...`
2. Участники **отвечают (reply)** на сообщение со списком, например: `7 23 45 66 91`.
   Бот проверяет числа (ровно 5, диапазон 1–99, без повторов) и добавляет в список.
3. Админ закрывает запись: `/бинго_закрыть` → `Закрыт ❌`.
4. Админ тянет числа: `/тираж` (по одному) или `/тираж5` (пять подряд).
5. Как только у кого-то выпали все 5 чисел — бот сам объявляет победителя 👑.
   Если совпало у нескольких сразу — победители все.

Прочее: `/список`, `/числа` (выпавшие), `/бинго_стоп`, `/помощь`.

## Структура

```
bingo/game.py      — чистая игровая логика (без Telegram), покрыта тестами
bingo/handlers.py  — обработчики Telegram-команд
bot_polling.py     — запуск на своей машине / VPS (long polling)
bot_webhook.py     — запуск на бесплатном PythonAnywhere (webhook + Flask)
tests/test_game.py — 32 юнит-теста (pytest)
```

## Про ошибку `Cannot connect to host api.telegram.org:443 ssl:...`

На **бесплатном** PythonAnywhere исходящий трафик идёт только через их
HTTP-прокси и только к белому списку доменов. `api.telegram.org` в белом
списке **есть**, но:

- **aiogram/aiohttp** не ходит через прокси автоматически → та самая ошибка;
- вечный polling-процесс на free-тарифе всё равно убивают.

Решение в этом проекте: библиотека **pyTelegramBotAPI** (работает через
`requests`, который прокси подхватывает сам) + **webhook** вместо polling.

## Запуск локально / на VPS

```bash
pip install -r requirements.txt
export BOT_TOKEN="токен_от_BotFather"
python bot_polling.py
```

## Запуск на PythonAnywhere (бесплатно)

1. Залейте файлы проекта, `pip install --user pyTelegramBotAPI flask`.
2. Web → Add a new web app → Flask (Python 3.10+).
3. В WSGI-файле импортируйте `app` из `bot_webhook.py` и задайте переменные:
   ```python
   import os, sys
   sys.path.insert(0, "/home/ВАШЛОГИН/bingo-bot")
   os.environ["BOT_TOKEN"] = "токен_от_BotFather"
   os.environ["WEBHOOK_HOST"] = "https://ВАШЛОГИН.pythonanywhere.com"
   from bot_webhook import app as application
   ```
4. Reload web app, затем откройте один раз в браузере:
   `https://ВАШЛОГИН.pythonanywhere.com/set_webhook`

Нюанс free-тарифа: приложение нужно продлевать кнопкой "Run until 3 months
from today" раз в 3 месяца, иначе его усыпят.

Альтернативы: Render free (webhook, просыпается от запроса Telegram),
Oracle Cloud Always Free (polling), свой ноутбук.

## Тесты

```bash
python -m pytest tests/ -v
```

Покрыто: парсинг чисел (разделители, диапазон, дубликаты), регистрация
(повторная запись, закрытие, пустой список), розыгрыш (уникальность чисел,
победа ровно при 5/5, одновременные победители, симуляция 20 полных игр),
рендер списка, персистентность JSON-хранилища и устойчивость к битому файлу.

## Настройка команд в BotFather (опционально)

Русские команды (`/бинго`) Telegram в меню не регистрирует, поэтому у каждой
есть латинский дубль: `bingo`, `close`, `draw`, `draw5`, `list`, `drawn`,
`stop` — их можно добавить через `/setcommands`.
